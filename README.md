# Ruimte om te spreken

Website voor de presentatie- en sprekerscoachingpraktijk van Pepijn Jansen.

## Bestanden

- `index.html` — Volledige one-page website met interactieve intake-flow
- `hero.png` — Hero-beeld (coulisselandschap Drents-Friese Wold)
- `pepijn-portrait.png` — Portretfoto Pepijn
- `breaker.png` — Visual breaker (handen in gesprek)
- `village.png` — Contactsectie achtergrond (Oldeberkoop)

## Technisch

- Geen dependencies, geen build stap
- Pure HTML/CSS/JS
- Fonts via Google Fonts (DM Serif Display + Nunito Sans)
- Responsive (desktop, tablet, mobiel)

## Status

Prototype / referentie voor Wix Studio implementatie.
